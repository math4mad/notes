# 图书馆入口建议 · 投递与成功率台账

> 主人 1001 令（2026-10-02）：**没有邮箱的就不管**；**若两馆有回音，再发 1–2 线城市**；
> **做成功率的统计，衡量方法的说服力**。

## 一 · 方法（被投递之物）

把图书馆入口的**「安检」与「入馆」两段解耦** —— **安检前置 · 篮子预存**：

1. 馆外设预存区，备带编号的篮子；
2. 开门前的等候时段，读者将包／电脑放入篮子、登记取对号牌，馆方**提前安检并加一次性封条**；
3. 开馆后凭牌取篮、走「已安检」通道，**免二次安检**；
4. 篮数按早高峰配置；封条破损者重检。

正文见 `proposal.md`。本质＝排队论**前置预处理／缓冲**。

## 二 · 为什么记成功率

投书 ＝ 一次**说服力实验**：一个方法若真有说服力，应能换来**回音、乃至采纳**。
故以**小样本、分线城市**统计——

| 指标 | 定义 |
|---|---|
| **回复率** | 有回音数 ／ 投递数 |
| **正向率** | 明确推进／采纳数 ／ 投递数 |
| **退信率** | 退信数 ／ 投递数 |

它衡量的不是"我们说得对不对"，而是"**这个说法能不能撬动对方**"——正是**说服力**。

## 三 · 扩张律（主人令）

1. 先投 **一线大馆**：广州、上海（各一封）；
2. **若得回音** → 扩至 **1–2 线城市**大馆；
3. 无回音 → 不扩（样本即结论的一部分）。

## 四 · 台账与出数

- 台账：`outreach.csv`（一行一馆）
- 出数：`python3 rate.py`

状态取值：`pending`（已投未复）· `ack`（礼貌回复）· `positive`（推进/采纳）· `negative`（婉拒）· `bounce`（退信）
