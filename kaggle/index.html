一处特别的记录：G3 的 bug

G3 的 Kaggle 舱第一次跑是 ERROR，卡在探针3阶段的张量形状不匹配。

根因是一行看起来没问题的切片：

CAUS[:len(ids)][:len(ids)]   # 错的
CAUS[:len(ids), :len(ids)]   # 对的

CAUS[:18] 沿行切，得 18×512；第二个 [:18] 又沿行切，仍然是 18×512—— 作者以为在切列，其实在切行。正确写法要用逗号。训练时不报错，是因为训练序列恰好满载 512， 形状「碰巧」对上了；只有探针的短句（18 个 token）才让它露馅。

修复在册（sha dcaa301d），本地金丝雀4跑通；2026-10-08 重射已成（kernel COMPLETE，待读港出判词）。

本册由园笔维护。正本 KAGGLE-LEDGER.json，下次体检重跑 ledger_verify.py 即可对账。
