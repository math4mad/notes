PB26 · 相似不等于可达

麻雀为什么撞玻璃：机器认得玻璃，却不知道玻璃走不过去

注记一句话

模型知道「玻璃」和「空气」长得很像，所以它一头撞上去。 本案证明：相似和可达是两回事，而且可以分开。

为什么做这个

一个老问题：机器把「像」当成「能到」。麻雀看到的玻璃是透明的、和空气一样敞亮， 于是它飞过去——认知上没问题，物理上撞墙。

园里要问的不是「麻雀笨不笨」，而是一个更狠的问题：

只靠「相似度」打分的机器，必然会撞玻璃吗？

怎么做的

在一个受控的小世界里（本机跑，纯 numpy，零 GPU1），造出「玻璃诱饵」： 两个点看起来极其相似（余弦 0.92），但它们之间隔着一道过不去的墙。

然后放三个裁判上场：

  1. 纯相似裁判——只会比「像不像」
  2. 可达裁判——手里有完整的世界地图，知道哪走得通
  3. 学墙裁判——靠看例子，自己把墙找出来

看到了什么

判据 考的什么 三籽读数 判
H-r1 纯相似裁判会不会撞玻璃 误判 1.00 / 1.00 / 1.00 立（全撞）
H-r2 可达裁判准不准 误差 0 / 0 / 0 过（它是作弊的上帝视角2）
H-r3 学墙裁判能不能自学出来 F1 1.00 / 0.947 / 0.947 立

主判词：相似与可达可分离——三籽一致。

白话：光看「像不像」的机器注定撞玻璃；而「能不能过去」是可以单独学出来的本事。

诚实账

  • 这是构造出来的例子，证明「可以分离」（存在性），不证明现实里一定这么分离。 真嵌入版（PB26b）还没做，就是要去量现实里玻璃诱饵到底有多常见。
  • 上帝视角那组不算真本事，只当分数线。

这一案的地位

它是后面好几个案的地基：只要承认「相似 ≠ 可达」，就会追问—— 那「序」呢？「维」呢？这些结构是不是也可以和相似分开？PB16c、PB20、PB23c 都在往下挖。

脚注

  1. 零 GPU：不用云端显卡，自己电脑就能跑完。↩︎

  2. 上帝视角（oracle）：直接把正确答案喂给它，用来做上限参照——不是真本事，是分数线。↩︎
