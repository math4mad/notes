P5 · 上下文锚定（五部曲）

「省图」在浙江和广东意思不同——能不能找到一根「换域」的杆子把它推过去？

注记一句话

能否找到一根线性「方向杆」，加上就把「浙江的图书馆」推成「广东的图书馆」？ 同词型内推得动（满分）；跨词型推不动——三档模型一致，不是模型太弱；而省名位那根杆子只是「同一个词」的方向，不是语义。

为什么做这个

「意义由上下文决定」是常识，但机制是什么？本案把「上下文锚定」逼成一个可动手的因果实验：能「加一根杆子就换义」，就说明锚定是线性编码的。

五步

步 做了什么 主结果
P5 GPT-2，读目标词处 换义 1.000 / 跨词型泛化 0.000
P5b 只改读出位→省名处 泛化 1.000——但疑似「同一 token」，非语义
P5c 换中文模型 Qwen2.5-0.5B 复证 目标词位泛化仍 0.095→非模型太弱
P5d 施杆于没见过的省名 泛化 0.000（双模型）→省名位那根确是 token 身份
P5e 规模升 3 倍：Qwen2.5-1.5B 目标词位泛化仍 0.000→规模非其因

判词

检验 GPT-2 (124M) Qwen (490M) Qwen (1.54B) 结论
换义（同词型内） 1.000 1.000 1.000 恒立——方向真、可干预
泛化 @目标词位 0.000 0.095 0.000 恒破——跨词型推不动
泛化 @省名位 — 1.000 1.000 立，但系 token 身份
泛化 @**未见省名** 0.000 0.000 — 破——坐实「非语义」
器具自检（乱杆子） 0.000 0.083 0.042 器净
干预是否出流形 未出（余弦 .979） — — 非 OOD 假象

主判词： > 「域切换方向」在同一词型内真实可干预；跨词型不存在语义域方向。 > 三档规模（124M→1.54B）一致 → 非容量之限；施于未见标记即失效 → 省名位那根系 token 身份。

一个诊断

P5 那个 0.000 太可疑，量了两根杆子的夹角：

读哪里 「图书馆」杆 vs 「美食」杆 的余弦
省名处 +0.992（几乎重合）
目标词处 +0.288（各说各话）

层扫描：省名位那根从第 0 层（嵌入层）即存在，全层泛化满分——正是「同一个 token 的方向」的特征， 不是「越深越分明的语义方向」。于是 P5d 直取未见省名一试，应声而破。

诚实账

  • 语料是模板造的，证的是「可/不可」，不是现实里有多常见
  • 省名位的 1.000 含 token 同一性——已由 P5d 拆穿，不当作语义证据
  • 三档模型仍小（124M/490M/1.54B）；更大规模复证仍候
  • 换义 1.000 的 OOD 疑已诊：干预后表示仍紧贴流形（余弦 0.98），非假象
