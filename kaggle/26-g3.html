G3 · 三年级模型

给不给「注意力」，模型学得一样吗？——四臂消融

注记一句话

训练一个「三年级水平」的小模型，四种「视野规则」各训一遍，看给功课 / 不给 / 给假功课 / 自己学哪种真有用。 三阶段查下来，答案是：设计的「给他注意力」不承重——随便一个同稀疏度的乱掩码，效果一样好。

为什么做这个

园里主张：概念空间的成长像盖小区——不是加词汇，是加结构。「给他注意力」（设计者预烧「该看哪」）能不能替规模分担这活？四臂1对照：

臂 白话 给什么
given 给真功课 设计者规定的舱间视野
random 给假功课 同稀疏度的乱划（安慰剂）
free 麻辣烫 随便看（无掩码）
learned 自己学 让它自己摸索视野

三阶段

① 金丝雀（Kaggle 舱）——修 bug

首射 ERROR。根因两处：CAUS[:n][:n] 链式切片（应 [:n, :n]）、rperm 未置 device。 修毕重射 COMPLETE。但判分 given 8/9 ≈ random 8/9——后来才知道这卷有毛病。

② 审计——发现卷坏了

普查九道探针2的候选：「序敏」「验收」两轴候选全在同一舱→ 落架3恒真，6/9 题没分辨力。 （runbook 早有预警，只是没修。）故金丝雀那个「8/9」主要是恒真 + 噪声，不是分离证据。 于是建 G3-Paper v1（掺跨舱干扰词），退化题 6/9 → 0/9。

③ 中炮 + 自然复证

  • 中炮（模板语料 3.36M 字符 / 26M 模型 / 1000 步）：五臂落架全 5/9——零分离。
  • 自然语料复证（THUCNews 中文新闻，10 主题=10 舱 / 11M 模型 / held-out loss）：
臂 test_loss
given（真掩码） 3.5519
random（乱掩码） 3.5486
free（无掩码） 3.8160
learned 3.7964

判词

主臂 given ≈ 安慰剂 random（差 0.003 可忽略）——真掩码与乱划同稀疏度掩码效果完全相同。 按冻本可证伪条款「对照臂同样过 → 结构非承重」：设计的「给定注意力」不承重。 但 free/learned 差 ~0.25 → 某种掩码（无论对不对）有益，但具体结构无关。 两语料（模板+自然）同向 → 零分离不是语料伪影。

诚实账

  • 规模仍小（26M / 11M；语料 3.4–4M 字符），远逊冻本之主炮（~90M / ~1B token）。
  • 自然复证用 THUCNews（新闻分词文本，10 主题），系另一实现，非 exp11「四舱快餐」。
  • 判词宜读作「在此规模、此掩码方式下，设计的舱结构不带来增益」——非绝对定谳。
  • 三次同型 device bug（新建索引张量未 .to(device)）——已立方法律。
提示为什么这页进了「夜航」册

G3 的 Kaggle 舱按设计只跑金丝雀（主炮属 5090）；中炮/自然复证在本机跑（零云端粮）。 本册实为园里实验合集。
