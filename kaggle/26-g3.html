G3 · 三年级模型

给不给课程，孩子学得一样吗？——四条臂的消融对照

注记一句话

训练一个「三年级水平」的小模型，用四种不同的「视野规则」各训一遍， 看给课程 / 不给课程 / 给假课程 / 自己学哪种真有用。 这批实验第一次上 Kaggle 时崩了，本页记录怎么修好的。

为什么做这个

园里主张：概念空间的成长像盖小区——不是加词汇，是加结构（维度/组织层级）。 要验证「课程」对加结构有没有用，就造一个模型当小白鼠，四臂对照：

臂 白话 给什么
given 给答案 直接告诉它注意力该看哪
free 麻辣烫 想怎么连就怎么连（全放开）
random 安慰剂 给一套乱打的规矩（对照组）
learned 自己学 让它自己摸索出视野

崩在哪（故事）

第一次上 Kaggle，given 臂训练成功（loss 从 6.95 收敛到 0.122，耗时 449 秒）， 但跑到探针（落架判分）阶段就 ERROR：

RuntimeError: The size of tensor a (18) must match the size of tensor b (512)

根因：一行切片

罪魁是这行看起来没问题的代码：

CAUS[:len(ids)][:len(ids)]   # 错
CAUS[:len(ids), :len(ids)]   # 对
  • CAUS[:18] 沿行切 → 得 18×512
  • 再 [:18] 又沿行切（已经 18 行了）→ 仍然 18×512
  • 作者以为在切列，其实在切行。正确写法要用逗号。

为什么训练时没崩？ 因为训练序列恰好满载 512，18×512 这种错形状碰巧对上了。 只有探针的短句（18 个 token）才让它露馅——典型的「撞大运式正确」。

怎么修的

  1. 三处 CAUS[:n][:n] 全改成 CAUS[:n, :n]（训练段两处 + 探针段一处）
  2. 本地金丝雀1跑通：给定臂 20 步，探针能出分（不再崩）
  3. 重新推上 Kaggle（修复版 g3_kaggle.py sha dcaa301d）

警告一个大警告：这是金丝雀规模

本舱模型仅 10M（d384/L6）、2500 步、语料 166 篇——不是冻本所指的主炮（~130M / ~1B token / 5090）。

在此规模下，主臂 given（89%）与对照 random（89%）无差（差 0pt < 冻条 20pt）——按冻本可证伪条款 「对照臂同样过 → 结构非承重」，苗头指向「给定的注意力非承重」。

但小语料上各臂皆在记熟（落架 7–8/9 极可能系探针被记而非学会），故不足以下定谳。 判词暂缓，候主炮（那才是冻本所指之实验）。

注记及格线（冻本）

主臂 ≥85% 且对照 ≤65%，差 ≥20pt。本舱读数：主臂 89% 过、对照 89% 不达、差 0pt 不达。
