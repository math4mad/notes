随身词典 · 傻瓜版

每个词一句话，读完就能跟上园里的实验笔记

注记这一页是干什么的

园里的实验笔记写得像密电码，因为写的人（园笔）自己用惯了。这一页把它们翻译成人话。

读书法：每个词给 一句话定义 + 一个比喻。正文里凡是第一次出现的难词，都会挂个脚注 [^词] 指向这里。

一、基础：什么是「概念空间」

词 一句话 比喻
概念 一个念头、一样东西在脑子里的位置 教室里的一个座位
概念空间 把所有概念摆进一个空间，让「像的东西」离得近 座位按关系排：亲戚坐一桌、同事坐一桌
维度 / 维 描述一样东西的一根「尺子」 一个人可以用身高、体重、年龄三个数描述，就有三维
义素 概念被拆开后剩下的最小意义块 把「苹果」拆成〔能吃〕〔圆〕〔红/绿〕〔水果〕
基向量 一根「尺子」的方向，量的就是这一维 拿「甜度」当一把尺子，从 0 到 10 量苹果
义素基向量 上文两个合起来：用一组尺子来量一个词的意义 给每个词打一份「多维体检表」
嵌入 / 词向量 把词变成一串数字，让机器能算 给每个词发一张「身份证号」，相似词的号也相似
相似度 两个概念有多像，0 到 1 之间 脸的相似度：亲兄弟 0.9，路人 0.1
α 距离 两个词在空间里隔多远 地图上两点之间的直线距离
θ 距离 两个词方向差多少（不管远近） 两个人朝不同方向走，夹角多大

二、算法：机器怎么算

词 一句话 比喻
MaxSim 拿你的词，去每个柜子里逐词比一遍，取最像的那个当柜子的分数 找失物：翻遍每个抽屉，看最像的那件
贝叶斯更新 看到新证据后，给各柜子的「可能性」重新打分 侦探看一条新线索，重排嫌疑人名单
先验 / 后验 先验=看证据前猜的；后验=看完证据后改的 开赛前押注 vs 看到比分后改注
似然度 这条证据在某柜子下有多「该出现」 在烤串摊闻到孜然味，这很正常（似然高）
概率分布 每个柜子各占多少份，加起来是 100% 蛋糕切成的块
ΔW 子空间 训练时权重改动了的那些方向 一道题做错后，脑子里被划重点的那几页
秩 / 有效秩 一组数据里真正独立的方向有几根 全班答题卡，其实只有三种答案风格，秩就是 3
残差 用简单模型解释完还剩下来、没法解释的部分 预算花完还剩的那笔「意外支出」
GS 残差谱（Gram-Schmidt） 一层层问「还能榨出多少新方向」，画成图 挤橙子，看第几杯开始没汁了
序敏轴 特别依赖「顺序」的那根尺子 「先放盐后放糖」和「先放糖后放盐」味道不同
落架 模型学到的是真本事还是只记住了架子 会骑车 vs 只会背骑车的口诀
字面 / 落架分轴 把「背得牢」和「真学会」分开考 默写满分 vs 举一反三
上下位关系（hypernym） A 是 B 的一种（苹果→水果） 家谱里的父子关系

三、训练：怎么把模型练出来

词 一句话 比喻
训练 / 训 让模型看大量例子，逐步调参数 练琴
步 / step 看一小批例子、调一次参数，叫一步 练习曲弹一遍
籽 / 种子（seed） 固定随机数，保证同条件能重跑出同结果 洗牌前先把牌堆摆成同一个样子
三籽 / 多籽 换三个不同的随机起点各跑一次，看结论稳不稳 三个人分别做同一个实验，都说成立才可信
臂 / 试验臂（arm） 实验的一个对照分支（如「给答案」组 vs「自己学」组） 临床试验的对照组、实验组
对照 / 安慰剂臂 什么都不给或给假的，看结果是不是碰巧 给糖丸的那组
消融 / 消融臂（ablation） 拆掉一个零件再跑，看少了它行不行 拆掉自行车的刹车，看看还骑不骑得动
课程 / 课程学习 先学简单的再学难的 教材从一年级往上编
掩码 / mask 挡住一部分信息，逼模型只用剩下的 考试时盖住参考书
LoRA 不改大模型本体，只挂一小块「贴纸」微调 原书不动，贴一张便签
微调 / fine-tune 拿现成模型再练一小会，适应新任务 会了钢琴转学电子琴
ckpt / 检查点 训练中途存下的存档，可回滚 游戏存档
损失 / loss 模型错了多少，越小越好 考试扣的分
tokens 文本被切成的最小单位（字/词片段） 用积木搭句子，每块积木就是一个 token

四、实验：园里的行话

词 一句话 比喻
PREREG / 冻稿 开跑前先把判据写死、盖章，防止事后找理由 考试前定好分数线，考完不许改
判据 / H-判 「什么样算成立、什么样算失败」的明文规矩 黑纸白字的验收标准
H-x0 / H-g1 之类 判据的编号（H = Hypothesis 假说） 第 1 条、第 2 条规矩
射 / 开炮 正式把实验跑起来 按下发射键
弹 / 弹药 待跑的实验脚本 上膛的子弹
舱 / 落舱 在 Kaggle 云端跑实验的容器 发射台
本机 / 零 GPU 在自己电脑上跑，不用云端 厨房里做小份试吃
夜航 挂在云端夜里跑，醒来收结果 睡前按下洗衣机
封条 / commit 冻稿时的代码存档编号，可追溯 合同上的骑缝章
sha / 哈希 一串指纹码，文件改一个字就全变 信封火漆印
判词 / 定谳 实验读完后给出的正式结论 法官宣判
破 / 立 破=判据失败；立=判据成立 考试没通过 vs 通过
归零 结果不可信，整案作废重来 卷子判错，重考
膝 / 拐点 曲线突然弯折的地方，暗示「结构变了」 走路突然上坡
平线 曲线是平的，说明没变化 心电图一条直线（但要区分真平 vs 没测到）
诚实账 主动写下实验的缺陷和不确定 自我检讨
